# Crypto Price Tracker 💰

A simple Python script to track cryptocurrency prices using CoinGecko's API.

## Features
- 📈 Fetch real-time cryptocurrency prices
- 📐 Supports multiple cryptocurrencies

## How to Use
1. Run `python price_tracker.py`
2. Enter the cryptocurrency name (e.g., "bitcoin", "ethereum")
3. View the current price in USD
